The four combinations, header only

The US set shows a quiet grey pill, so the default stays calm. The Europe set shows the accent pill, like Figures in EUR. The two switches are independent. Europe in USD is allowed: the factors are published in dollars.

Phone top bar: the set stays visible with the drawer closed

At 390 px the sidebar is a drawer. The top bar shows the currency chip as today and a Europe chip only when the Europe set is on. The US set adds no chip, to save room.

The switch row, close up
